## 梯子、机场、VPN 和客户端是什么关系

这几个词经常混用，但它们不是完全相同的东西：

| 名称 | 简单理解 | 购买时真正需要确认什么 |
| --- | --- | --- |
| 梯子 | 对跨境网络工具和服务的俗称 | 你买到的是服务、订阅还是单独软件 |
| 机场 | 提供节点和订阅的服务商 | 套餐、线路、节点、流量、设备和售后 |
| VPN | 一类网络连接技术，也常被用作产品名称 | 是否适合当前网络、支持的平台和连接方式 |
| 节点 | 实际连接的服务器入口 | 地区、负载、倍率、可用性和解锁情况 |
| 客户端 | 导入订阅并管理节点的软件 | 系统支持、订阅格式、下载来源和更新状态 |

购买机场订阅后，通常还要把订阅链接导入兼容客户端。少数服务商提供自己的 Windows、macOS 或 Android 客户端。软件本身不等于线路服务，只有客户端而没有可用订阅，通常不能直接连接。

更完整的概念对比见：[梯子和 VPN 是一回事吗？](docs/tizi-vs-vpn.md)

## 选择梯子最重要的六个问题

### 1. 先看付款周期，不要先看折扣

年付价格通常更低，但机场存在线路调整、入口失效、运营变化和停止服务风险。新用户优先月付；只有实际使用一段时间后，才考虑半年或年付。部分低价年付套餐没有同规格月付版本，不能简单把年价除以 12 当作真实月付价格。

### 2. 分清“每月流量”和“周期总流量”

有些套餐每 30 天重置，有些按自然月重置，有些是整个购买周期一次性到账。未使用流量是否结转、续费是否叠加流量，也可能不同。下单前至少确认：

- 流量多久重置一次；
- 未使用流量是否清零；
- 提前续费会不会覆盖旧套餐；
- 不限时流量是否有实际有效期。

### 3. 设备数和在线客户端不是一回事

“不限客户端”“不限设备”不一定代表可以多人共享，也不代表无限并发。家庭、多手机电脑或小团队使用时，要继续确认账号共享规则、在线 IP 限制和公平使用政策。

### 4. 标称速率不是实际速度

50 Mbps、500 Mbps 或 2.5 Gbps 是标称上限，不是你一定能跑到的速度。真实表现还受本地宽带、运营商、入口、节点距离、晚高峰负载和终端性能影响。

### 5. 不要只看“IPLC、IEPL、原生 IP、全解锁”

线路名称和解锁标签可以作为筛选条件，但不能单独证明稳定。更可靠的做法是用短周期套餐，在工作日和周末的晚高峰分别测试常用节点、视频、AI 服务和日常网站。

### 6. 看清退款和换套餐规则

光年梯、寰宇云、可可云不提供退款；大哥云不支持原路退款。尔湾云直接新购套餐可能替换旧套餐并清空剩余流量和天数。付款前保留套餐和规则截图，比事后争议更有效。

## 免费梯子靠谱吗

免费梯子、免费节点和公开订阅通常面临几类问题：来源不明、多人共用、随时失效、流量被滥用、客户端被篡改，以及难以判断运营者如何处理日志和数据。

如果只是临时测试，也不要：

- 在来历不明的软件里输入主账号密码；
- 把机场订阅链接交给陌生在线转换网站；
- 使用同一连接处理银行、工作后台或其他敏感账户；
- 因为“永久免费”承诺关闭系统安全软件或授予无关权限。

详细风险和低成本替代方案见：[免费梯子靠谱吗？](docs/mianfei-tizi.md)

## 购买后怎么使用

一般流程是：

1. 在服务商页面注册并购买套餐。
2. 在用户中心找到订阅链接或官方客户端。
3. 从项目官方发布页下载兼容客户端。
4. 导入订阅并更新节点列表。
5. 选择一个节点，开启系统代理或 VPN 权限。
6. 先测试普通网页，再测试自己的主要使用场景。

不要把订阅链接公开到 GitHub、聊天群、截图或在线转换站。订阅链接通常包含访问凭据，一旦泄露应立即在服务商后台重置。

Windows、macOS、Linux 和 Android 可先了解 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev)、[v2rayN](https://github.com/2dust/v2rayN) 或 [FlClash](https://github.com/chen08209/FlClash) 等开源客户端，但最终要以服务商支持的订阅格式为准。完整说明见：[梯子软件怎么选与怎么下载](docs/tizi-ruanjian.md)。

## 常见问题

### 2026 年哪个梯子最好用？

没有对所有地区和运营商都最好的单一答案。低流量用户、家庭多设备、AI 办公和大流量视频需要的套餐不同。优先从月付和明确限制的套餐中筛选，再用自己的网络测试。

### 好用的梯子一定很贵吗？

不一定。价格高可能来自更多流量、设备、专线或服务成本，但不能自动证明更稳定。价格很低也不一定不能用，只是通常需要在流量、设备、退款或长期稳定性上做取舍。

### 梯子推荐应该看延迟还是速度？

两者都不能单独决定体验。延迟影响交互，吞吐影响下载和视频，丢包、断流和晚高峰波动则影响持续使用。测试时应记录多个时间段，而不是只保存一次最高测速截图。

### 月付、年付还是不限时流量包？

- 第一次购买：优先月付。
- 已经稳定使用一段时间：再考虑半年或年付折扣。
- 偶尔使用或准备备用：考虑不限时流量包。
- 需要持续大流量：比较月付流量、设备数和重置规则，不要只看年付总价。

### 是否应该准备备用梯子？

如果网络连接直接影响工作，可以准备不同服务商的小额月付或不限时备用包，但没有必要为备用方案购买昂贵大流量年付。
