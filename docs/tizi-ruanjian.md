# 梯子软件怎么选？下载来源、客户端与设备支持

[返回 2026 梯子推荐](../README.md)

梯子软件通常指用于导入订阅、选择节点和管理系统代理的客户端。它和付费线路不是同一个东西：购买机场一般得到订阅服务，客户端只是使用订阅的工具。

## 先确认订阅格式，再下载软件

不要先下载一堆客户端。购买前先在服务商帮助文档或客服处确认：

- 是否提供通用订阅 URL；
- 支持 Clash/Mihomo、V2Ray/Xray、sing-box 还是专用客户端；
- 是否强制使用官方客户端；
- Windows、macOS、Android、iOS 和 Linux 分别支持什么；
- 是否限制在线设备、IP 或同时连接数量。

订阅格式不兼容时，即使软件本身正常也无法导入。

## 常见平台怎么选

| 平台 | 可以了解的客户端 | 适用情况 |
| --- | --- | --- |
| Windows | Clash Verge Rev、v2rayN、FlClash | 通用订阅、需要规则分流或多个配置 |
| macOS | Clash Verge Rev、v2rayN、FlClash | 先确认芯片架构和最低系统版本 |
| Linux | Clash Verge Rev、v2rayN、FlClash、sing-box | 图形界面或命令行环境 |
| Android | FlClash、v2rayNG 或服务商客户端 | 安装前核对开发者和 APK 来源 |
| iPhone/iPad | App Store 中与订阅兼容的客户端 | 可用性、地区和价格以 App Store 当前页面为准 |

这些名称不是唯一选择，也不代表所有机场都兼容。

## 官方下载入口

优先从开发者自己的发布页下载，不使用搜索广告、网盘搬运或陌生“绿色版”：

- [Clash Verge Rev 官方仓库](https://github.com/clash-verge-rev/clash-verge-rev)——仓库说明支持 Windows、Linux 和 macOS，安装包位于 Releases。
- [v2rayN 官方仓库](https://github.com/2dust/v2rayN)——官方说明支持 Windows、Linux 和 macOS，并提供 v2rayNG 移动端入口。
- [FlClash 官方仓库](https://github.com/chen08209/FlClash)——跨平台图形客户端。
- [sing-box 官方仓库](https://github.com/SagerNet/sing-box)——通用代理平台，更适合了解配置的用户。

下载后还可以核对文件哈希、签名或开发者发布说明。不要从名字相似的第三方仓库下载。

## 通用使用流程

1. 从服务商用户中心复制自己的订阅链接。
2. 打开客户端的配置、订阅或 Profiles 页面。
3. 通过 URL 导入订阅。
4. 更新配置并选择节点。
5. 根据客户端开启系统代理或 VPN 权限。
6. 先打开普通网页测试，再检查自己的主要使用场景。

订阅链接不要放进公开仓库、截图或在线转换网站。它通常等同于账号访问凭据。

## 手机和电脑有什么不同

### Windows 和 macOS

桌面系统更适合管理多个订阅、规则和节点。下载时注意 CPU 架构、系统版本和安装包格式。Windows 不要长期使用已经停更且来源不明的旧客户端镜像。

### Android

如果使用 APK 安装，应确认 GitHub 仓库、开发者签名或服务商官方帮助页。首次运行通常需要系统 VPN 权限，但不应索取通讯录、短信或辅助功能等无关权限。

### iOS 和 iPadOS

客户端分发受 App Store 地区和政策影响。不要购买多人共享、来源不明的 Apple ID，也不要在陌生网站输入自己的 Apple 账号密码。应用是否仍可下载、价格和开发者名称，应以 App Store 当前页面为准。

## 常见问题

### 导入订阅后没有节点

先确认套餐是否生效、订阅链接是否完整、客户端是否支持该格式。然后在服务商后台重置订阅，再重新导入。不要先把链接交给陌生转换站。

### 节点全部超时

依次检查套餐流量和有效期、更新订阅、系统时间、本地网络、客户端内核和服务商公告。也可以用手机热点与家庭宽带交叉测试，区分本地网络问题和服务问题。

### 客户端显示延迟低，为什么速度仍慢？

延迟只代表小数据包往返时间，不能代表持续吞吐、丢包和晚高峰负载。需要用实际网页、下载或视频场景继续测试。

### 可以同时安装多个梯子软件吗？

可以安装，但不要同时开启多个系统代理、VPN 或 TUN 模式。多个客户端同时接管网络容易造成路由、DNS 和端口冲突。
